# Atalhos de teclado

## Globais

| Atalho | Ação |
| --- | --- |
| ++ctrl+shift+space++ | abre a **captura rápida** de qualquer lugar do sistema (mesmo com o app na bandeja) |

O atalho é fixo; não há como trocá-lo pela interface.

## Captura rápida

| Atalho | Ação |
| --- | --- |
| ++enter++ | captura a tarefa no Inbox |
| ++esc++ | fecha a janela |

## Terminal embutido

| Atalho | Ação |
| --- | --- |
| ++ctrl+"'"++ | mostra ou esconde o painel do terminal (a tecla à esquerda do 1; no teclado US, ++ctrl+grave++) |
| ++ctrl+shift+"'"++ | terminal em tela cheia |
| ++shift+enter++ | nova linha sem enviar (útil no Claude Code e em outros programas de terminal) |
| duplo clique na aba | renomeia a aba; ++enter++ salva, ++esc++ cancela |

## Notas (editor)

| Atalho | Ação |
| --- | --- |
| ++slash++ | menu de comandos (títulos, listas, checklist, tabela, imagem…) |
| `@` | menciona uma tarefa, projeto, contexto ou página de caderno |
| ++arrow-up++ / ++arrow-down++ e ++enter++ | navegam e escolhem nos menus `/` e `@` |
| ++esc++ | sai do Modo foco (de tarefas e de páginas de caderno) |

O editor também aceita os atalhos comuns de formatação de texto (negrito, itálico etc.).

## Cadernos

| Atalho | Ação |
| --- | --- |
| ++arrow-up++ / ++arrow-down++ e ++enter++ | navegam e abrem um resultado da busca |
| ++esc++ | fecha a busca |

## Campos e listas

| Atalho | Ação |
| --- | --- |
| ++enter++ | confirma o campo (subtarefa nova, tag, link externo, diretório) |
| ++esc++ | cancela a edição de subtarefa ou fecha a lista de tags |
| ++backspace++ com o campo vazio | remove a última tag do campo de tags |
