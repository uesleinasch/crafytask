# Desenvolvimento

O CrafyTask é código aberto (MIT) e feito com Electron, React 19, TypeScript e SQLite
(`better-sqlite3`). Estas páginas são para quem quer rodar o código, entender a estrutura ou
contribuir.

| Página | Conteúdo |
| --- | --- |
| [Arquitetura](arquitetura.md) | os três processos, o caminho de um dado, banco, integrações |
| [Como contribuir](contribuir.md) | preparar o ambiente, testar, abrir um PR |
| [Fluxo git](fluxo-git.md) | branches, commits, PRs e como uma versão é publicada |
| [Scripts npm](../comandos/scripts-npm.md) | todos os comandos do `package.json` |

Para o detalhe de cada tela, veja o [Mapa da interface](../ui/README.md) na Referência técnica.
