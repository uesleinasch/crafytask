# Integrações

Todas as integrações são **opcionais** e ficam em **Configurações** (ícone de engrenagem na barra
superior), no grupo *Integrações*. Um ponto ao lado de cada uma mostra o estado: verde (conectada
ou rodando), cinza (desligada) ou vermelho (MCP ligado mas sem conseguir iniciar).

As telas de configuração trazem um guia passo a passo embutido; estas páginas repetem esse guia e
explicam o que cada integração faz e não faz.

| Integração | Direção | Para quê |
| --- | --- | --- |
| [Notion](notion.md) | CrafyTask → Notion | espelhar tarefas, notas e cadernos num banco do Notion |
| [Google Calendar](google-calendar.md) | CrafyTask → Google | ver blocos de tempo, agendamentos e prazos na sua agenda |
| [Jira](jira.md) | Jira ↔ CrafyTask | importar issues atribuídas a você, transicionar status, editar campos, enviar worklog |
| [MCP](mcp.md) | assistente ↔ CrafyTask | deixar o Claude Code (ou outro cliente MCP) ler e organizar suas tarefas |
| [Ditado (Handy)](handy.md) | Handy → CrafyTask | falar e ver o texto no campo em que o cursor está |

!!! info "Nomes antigos preservados"
    Alguns nomes criados pelas integrações continuam com "TickTask" para não duplicar dados de
    quem já usava o app: a agenda **TickTask** no Google, a página **Cadernos TickTask** e o banco
    **GTD APP** no Notion.
