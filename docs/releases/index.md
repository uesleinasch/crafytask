# Releases

Cada versão do CrafyTask tem uma página aqui, com data, destaques, novidades, correções e notas de
atualização. O mesmo texto é usado como descrição da
[GitHub Release](https://github.com/uesleinasch/crafytask/releases), onde ficam também os
instaladores (`.deb` e AppImage) e a lista de commits da versão.

| Versão | Data | Resumo |
| --- | --- | --- |
| [v3.19.0](v3.19.0.md) | 21/11/2026 | conectar com Google num clique, permissões de agenda e Drive, projetos ligados a metas, timer para ao finalizar |
| [v3.18.0](v3.18.0.md) | 20/11/2026 | servidor MCP: histórico da task, sessão de trabalho pela pasta, briefing, notas sem perda e por seção, busca geral, prompts, notificação; aba Histórico na task |
| [v3.17.0](v3.17.0.md) | 20/11/2026 | interface nova sobre o Ant Design, tema claro e escuro, plano do dia, calendário com time blocking, revisão semanal guiada, dashboard novo, preferências de fluxo de trabalho |
| [v3.16.0](v3.16.0.md) | 17/11/2026 | terminal em grupos no estilo do VS Code, diretório de trabalho no projeto, modo lista nos projetos, MCP como `crafytask` |
| [v3.15.0](v3.15.0.md) | 16/11/2026 | primeira versão como CrafyTask: rebrand visual, repositório novo, só Linux, site de documentação |

Versões anteriores foram publicadas com o nome TickTask, em outro repositório.

## Como instalar uma versão

Baixe o `.deb` ou o AppImage na página da release e siga o guia de [Instalação](../instalacao.md).
