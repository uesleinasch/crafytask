# v3.16.0

**Data:** 17 de novembro de 2026

Terminal no estilo do VS Code, diretório de trabalho por projeto, modo lista nos projetos e o
servidor MCP com o nome novo.

## Destaques

- **Divisão do terminal como no VS Code.** Dividir põe o terminal novo ao lado, no mesmo grupo, em
  vez de abrir outra aba. Com dois ou mais terminais, uma lista vertical à direita mostra todos, com
  os grupos ligados por `┌ ├ └`.
- **Diretório de trabalho no projeto.** As tarefas do projeto abrem o terminal nessa pasta, a menos
  que tenham uma própria.
- **Servidor MCP agora se chama `crafytask`.**

## Novidades

### Terminal

- Terminais organizados em **grupos**: **Dividir** abre um terminal novo no grupo focado; `+` abre
  um terminal num grupo novo.
- A barra de abas deu lugar a uma **lista vertical à direita** (aparece com dois ou mais
  terminais). Clique para focar, `×` no hover para encerrar, duplo clique para renomear.
- Botão direito → **Separar do grupo** tira um terminal da divisão.
- Cada painel de um grupo dividido tem um cabeçalho fino; o focado ganha borda laranja. As
  divisórias arrastam, com pelo menos 10% do grupo para cada painel.
- O cabeçalho do painel mostra o nome do terminal focado e ganhou o botão `×` para encerrá-lo.

### Projetos

- **Diretório de trabalho do projeto**, no detalhe do projeto (Escolher / Alterar / remover). A
  tarefa sem diretório próprio herda o do projeto: o campo mostra *do projeto*, **Alterar** grava
  um diretório só da tarefa e `↶` volta a herdar. Fica só no seu computador, como o da tarefa.
- **Modo lista** na listagem de projetos, ao lado das abas de status, com nome, próxima ação,
  status, progresso e prazo em uma linha. A escolha entre Cards e Lista fica salva.

### MCP

- O servidor se registra como `crafytask` e o `server_info` responde `app: 'CrafyTask'`. O comando
  em **Configurações → Servidor MCP** já vem com o nome novo.

## Correções

- **Terminal:** trocar de terminal, esconder o painel ou ir para tela cheia não quebra mais o
  layout de programas de tela cheia como o Claude Code. Cada terminal mantém a própria tela em vez
  de redesenhar a saída gravada.
- **Horizontes** e **Arquivadas** voltaram a rolar quando o conteúdo passa da altura da janela.

## Notas de atualização e compatibilidade

- **MCP:** quem registrou o servidor como `ticktask` continua funcionando, mas as tools aparecem
  como `mcp__ticktask__*`. Para usar o nome novo:

    ```bash
    claude mcp remove ticktask --scope user
    ```

    e registre de novo com o comando de **Configurações → Servidor MCP**. Detalhes em
    [MCP](https://uesleinasch.github.io/crafytask/integracoes/mcp/).
- As proporções da divisão do terminal agora valem enquanto o app está aberto; a preferência
  `terminal.splitRatio` deixou de ser usada.
- Para quem roda a partir do código: `npm run dev` passou a definir `ELECTRON_DISABLE_SANDBOX=1`.

Guia completo de instalação:
[uesleinasch.github.io/crafytask/instalacao](https://uesleinasch.github.io/crafytask/instalacao/).
